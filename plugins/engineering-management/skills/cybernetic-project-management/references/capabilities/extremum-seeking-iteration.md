# 自寻最优点的试探迭代（连续测量代替预知 + 步长律 + 优选法）

## R（原文摘引）
> 在系统实际进行运转之前永远不可能丝毫不差地知道一个工程系统的性质。因此，如果要求系统具有高度精确的控制性能，我们就必须采用连续理解和测量的控制原理。（第十六章 16.1）
> 为了运转稳定起见，临界电压差必须比干扰的振幅来得大。这样，自寻最优点系统的搜索损失不能够比系统中噪声的振幅小。（第十六章 16.3/16.6）
> 可以在所有情况下，无论 N 为多少，每次都以 0.618 或以 1−0.618=0.382 来选定下一次试验点的位置。这就得到华罗庚教授在文献[11]中提倡的"优选法"。（第十六章 16.8）

## I（解释）
1. **预知不可能，测量代替**：对象性质（新市场反应、新技术产能、团队对新流程的响应）永远无法事前精确知道——制造偏差 + 环境漂移 + 预料不到的剧变。出路：控制过程中的连续试探与测量代替事前调研；每次投入既是推进也是探针（理解与控制两重性）。
2. **步长两难是结构性的**：步子大 → 搜索损失大且易被噪声误导反转；步子小 → 收敛慢且跟不上漂移。变步长律：远离最优时按反馈斜率加大步长，接近时自动收小——探索期大步快试，稳定期小步微调。
3. **节奏夹在两个噪声之间**：试探/复盘节拍要快过环境漂移（需求变化）、慢过高频噪声（日常波动）。决策阈值必须大于噪声振幅，否则被随机波动牵着反复变向。
4. **搜索损失有下限**：探测精度不可能低于系统的噪声水平——想更精细，先改善度量，不是调更小的步子。
5. **单峰参数用 0.618 法**：已知"区间内唯一最优、两侧单调"时，黄金分割取点，每轮试验缩小 38%，N 轮后区间收缩 0.618^(N−1)，每步复用旧试验点。

## A1（原书案例 + 合成演练）
- 原书：熟练工人听机器声音、看仪表读数，反复调输入找最优运转点——自寻最优点系统把这套人工经验自动化（16.1，含 1943 年苏联工业试验的发明史转述）；飞机结冰改变气动特性，预调参数失效，靠连续寻优保持最优（16.1）。
- 合成演练（原书未提供项目案例，规则可复算）：迭代长度在 1–4 周间寻最优（假设单峰，评测=交付吞吐/协调开销）→ 第 1 轮试 2.47 周（0.382 位）与 2.53 周（0.618 位）→ 保留优侧，区间缩至 [1, 2.53]；4 轮后区间 <0.5 周，取 2 周。每轮只新增 1 次试验，符合 16.8 程序。

## A2（情境应用）
场景：进入新领域无法预先调研时；决定迭代/试验的幅度与节奏时；灰度发布/特性开关调参时；"要不要多调研再动手"的犹豫时。
语言信号：「没有足够信息怎么办」「先调研还是先干」「试验节奏怎么定」「步子迈多大」「unknown territory / iterate / probe / 试错」。
区分：model-approximation-identification 处理可建模可估算的对象；本卡处理连模型结构都未知的对象；feedback-cadence-design 定监控节律，本卡定主动试探节律。

## E（执行步骤）
输入契约：可调整的参数（或方案方向）+ 可测量的产出指标 + 单次试验成本 + 噪声水平（历史波动）。
1. 确认可试探性：产出对参数变化的响应可测、试验失败可承受。不可测 → 先建度量；不可承受 → 不适用本卡。
2. 定步长与节奏：初始步长 ≈ 敢承受的最大损失/2；节拍快过环境漂移、慢过高频噪声；方向反转阈值 > 2 倍噪声振幅。完成标准：三个数值及依据。
3. 单峰参数用 0.618 程序：区间 [a,b] 内先试 0.382/0.618 两点，保留优侧缩区间，迭代至区间满足精度。每轮复用上次结果。
4. 非单峰/多参数：变步长爬山——按当前反馈幅度定下一step（反馈强步子大），越过峰值（指标转降）即反号缩小步长。
5. 记录搜索损失：承认试探本身有成本（时间/资源），累计损失超过收敛收益时停止优化转交付。
输出契约：试探序列记录 + 当前最优区间/点 + 累计搜索损失 + 停止或继续判定。判停：产出不可测时不得开始试探。

## B（边界）
- 前提是"极值存在且基本稳定"：环境漂移快于搜索速度时永远追不上（16.3 干扰影响），此时该换问题不是换步长。
- 忽略时滞会把惯性当趋势误触发反向（16.5 警告）：调整后必须等一个完整响应周期再评效果——见 delay-compensation。
- 噪声大于信号时方向判断随机：先降噪（noise-filtering-estimation）再寻优。
- 0.618 法仅限单峰；多峰区间会锁进局部最优，需先分区或随机重启（成本另计）。
- 不适用于一次性决策（无法反复试验的场景）。
