# 多目标指标体系与权衡（六项清单 + 主要矛盾 + 向量指标）

## R（原文摘引）
> 我们将可以看到，它们有时是相互矛盾的。设计一个系统满足全部上述指标几乎是不可能的。……抓住主要矛盾和矛盾的主要方面，从实际情况出发，作出判断，其它是没有出路的，也不可能存在什么统一的放之四海而皆准的处理办法。（第一章 1.7）
> 如果把所有这八大指标综合成一个指标函数，再根据这一综合指标去控制生产过程，结果必然会使某个权重大的指标达到最优，而牺牲"次要的"指标，致使这些次要的指标根本得不到满足，这在实际问题中往往是不能允许的。（第二十一章 21.8）

## I（解释）
1. **指标族按对象定制**：原书六项（稳定性、稳态精度、过渡过程时间、超调量、积分泛函、抗扰性）转译为项目六项——交付稳定、长期偏差、恢复时间、过载幅度、累积代价、抗扰性。每个项目"有自己的主要指标"，不套通用 KPI。
2. **先分别评价再权衡**：逐项独立度量（不合成分数），承认全满足不可能。
3. **抓主要矛盾**：判断当前阶段的主要矛盾（交付压力？质量债？成本红线？），显式声明牺牲什么、保什么、依据是什么。权衡是情境判断，无万能公式。
4. **拒绝单一综合 KPI**：加权总分必然让高权重指标吞噬低权重指标（21.8 的失效机理）。替代方案：保留指标向量 → 淘汰被全面支配的方案 → 保留帕累托集 → 由决策者在不可比方案间显式取舍。
5. **口径先行**：超调量类指标必须事先声明计算口径（峰值−目标)/目标，及观测窗口；口径不明则度量不可比。

## A1（原书案例 + 合成演练）
- 原书：企业产量/品种/成品率/劳动生产率/成本/利润/流动资金周转八大指标若合成单指标控制生产，权重小的指标将根本得不到满足（21.8，企业管理情境例）；片面提高放大系数可把静差压到零但稳定性恶化（4.8）。
- 合成演练（原书未提供项目案例）：三个候选排期方案 A(快/质差/贵)、B(慢/质好/省)、C(全居中但每项都不如 A 或 B 的某项) → C 被全面支配淘汰，A/B 不可比 → 报告帕累托集 {A,B}，由决策者按当期主要矛盾（如发布窗口硬）选 A 并显式记录"牺牲质量换时间"。

## A2（情境应用）
场景：制定或修改项目目标/OKR 时；被要求"给个项目总分/健康分"时；进度质量成本冲突要拍板时；设计项目群考核指标时。
语言信号：「进度质量和成本怎么权衡」「能不能给个综合评分」「哪个方案更好」「KPI 怎么定」「trade-off / prioritization / 多目标」。
区分：本卡管"目标与指标怎么定和比"；baseline-variance-control 管执行期偏差怎么管；stability-health-check 管健康度判定口径。

## E（执行步骤）
输入契约：目标描述 + 至少 2 个候选方案（或当前单一方案）+ 各方案在指标维度的数据（可粗估但须标注）。
1. 把项目目标转译为 4–6 维指标向量，每维写明口径（怎么算、观测窗口多长）。完成标准：每维一句话口径。
2. 逐方案逐维度量，填指标矩阵。禁止任何加权合成。
3. 判主要矛盾：当前阶段哪一维不满足即项目失败（硬约束维），其余为优化维。完成标准：一句话"本项目当前主要矛盾是 X，因为 Y"。
4. 淘汰被支配方案（某方案每维都不优于另一方案），输出帕累托集与各方案取舍说明（各牺牲什么、换到什么）。
5. 若帕累托集 >1，交决策者显式选择并记录依据；若决策者要"合成一个分数"，引用 21.8 失效机理拒绝，改用带底线约束的主要矛盾法。
输出契约：指标口径表 + 指标矩阵 + 帕累托集 + 主要矛盾声明 + 决策记录。判停：无候选方案数据时先产出指标口径表，不评优劣。

## B（边界）
- 不适用于单指标场景——只有一维时无需本卡，直接最优化。
- 加权合成并非永远非法：指标少（≤2）且无硬底线时可合成（原书 1.7 允许单指标"抓主要矛盾"）；一旦出现"次要指标有底线"就必须回到向量法。
- 主要矛盾的判定需要调查研究依据（1.7），不得拍脑袋声明；判定错误会导致全盘取舍错误，记录判断依据备查。
- 不解决指标怎么测（数据问题看 noise-filtering-estimation），只解决指标怎么比。
