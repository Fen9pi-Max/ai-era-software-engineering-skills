# 自适应与自镇定（开关边界 + 复杂度定律 + 分组隔离 + 定点适应 + 模型参考）

## R（原文摘引）
> 只要把所需要的系统的平衡点用一个封闭的边界包围起来，并且建立一套开关装置，每当系统的运动曲线到达边界时，参数 ζ 就会改换成另外一个不同的值……系统就自动地摈弃那些不稳定的形式，保留稳定的运动形式，而自动达到稳定状态。（第十八章 18.1）
> 假设系统包含 100 个变量，p≅1/2¹⁰⁰，N=2¹⁰⁰≅10³⁰……达到终点场所需要的时间仍然要等于 3×10¹⁹ 个世纪。……假设 100 个变量可以分成 20 组，每组有五个变量……时间总数只是 20×3.2=64 秒。（第十八章 18.3/18.4）
> 我们根据普通的方法来设计系统而不采用自行镇定这种原理，只有当预先估计会有扰乱的时候才采用新的原理和开关装置。（第十八章 18.4）
> 适应性参数的调整，应使误差改变量 Δe(t) 和 e(t) 是反方向的，从而才能保证 e(t) 趋于零。（第十八章 18.6）

## I（解释）
1. **开关边界 = 自动恢复机制**：为关键指标预设红线边界，运动触线即强制切换工作方式（换人/换方案/降级范围），不可用形式被自动摈弃、可用形式被保留。恢复不靠外部救援，靠系统内预置的切换装置。
2. **复杂度定律（定量依据）**：随机试错的稳定概率 ≈ 1/2ⁿ——耦合变量每加一个，盲试成功率减半。100 变量整体盲试需 3×10¹⁹ 世纪；分 20 组×5 变量后只要 64 秒。结论：大系统绝不能"随便试错了再换"，必须先缩小搜索空间（预设结构约束）或先分解。
3. **按扰动范围分组隔离**：干扰通常只波及少数变量。按"预期风险波及谁"划分子系统，让扰动在组内消化、不传染全局；分组随主要风险类型动态重组。这是故障域隔离的控制论根据。
4. **定点适应优于万能适应**：常规流程为主，只为枚举得出的具体风险点（单点故障、可预见变更类型）预置切换预案，且要求一次切换即恢复——不做"万物皆可自适应"，也不裸奔。
5. **方向性检验（模型参考）**：以理想基准（模型/历史基线）为参照，任何改进行动必须使偏差缩小（Δe·e ≤ 0）——"越改越偏"的动作在数学上被禁止，这是过程改进的最低正确性标准。一成不变的规律换环境后完全丧失能力（18.5 警告），所以规则必须内嵌再校准机制。

## A1（原书案例 + 合成演练）
- 原书：阿施贝 homeostat 四磁铁自镇定装置——运动碰边界即随机跳换参数，稳定形式自动留存（18.2，转述实验）；100 变量 vs 20×5 分组的 3×10¹⁹ 世纪 vs 64 秒（18.4，数值已核）；自动驾驶仪"副翼信号接反"这一种意外，用开关在一次切换内纠正（18.5 构造情境）。
- 合成演练（原书未提供项目案例）：项目核心指标 = 交付吞吐，预设红线（连续 2 周低于基线 60% 触线）→ 触发切换：候选方案池 [降范围 / 换技术负责 / 冻结新需求 2 周]，切换后 1 个迭代内评估是否回到带内，未回带换下一候选。复杂度检查：全项目 40 个耦合决策项盲试 = 1/2⁴⁰ 不可行 → 先分组（产品决策组/技术决策组/人员组，各 ≤6 项），组内切换互不牵连 → 每组恢复时间从天文数字降为个位数迭代。

## A2（情境应用）
场景：设计项目应急预案时（不是写文档而是设计自动触发）；组织"要韧性不要僵硬"的争论时；环境剧变（需求突变/市场变化/核心人员离职）后的恢复；过程改进动作总不见效时。
语言信号：「预案怎么设计才不是摆设」「怎么让项目自动回正」「变更来了怎么应对」「改进措施怎么验收」「resilience / contingency / 自动恢复 / adapt」。
区分：redundancy-fault-tolerance 是失效前的结构备份；本卡是异常发生后的自动恢复机制；stability-health-check 判定何时触线，本卡规定触线后怎么办。

## E（执行步骤）
输入契约：关键指标及其正常带（基线 ± 容差）+ 可枚举的风险/变更类型清单 + 可承受的恢复时限。
1. 定开关边界：每项关键指标画红线（触线条件可观测、可自动判定），边界 = 正常带的包络。完成标准：每指标一条红线 + 判定数据源。
2. 备候选方案池：每条红线对应 2–3 个切换候选（降级/换将/冻结），按"一次切换即恢复"标准设计。完成标准：红线→候选映射完整。
3. 复杂度检查与分组：耦合决策项 >8 项时按风险波及范围分组，各组边界互不牵连；单组盲试候选 ≤4 个。完成标准：分组图 + 组规模上限说明。
4. 定点部署：只为枚举出的风险点部署开关（对照风险清单），常规流程不套自适应；每套开关写明触发→切换→验证→（未恢复）再切换的循环上限。
5. 改进动作方向性检验：每项过程改进前后测同一偏差指标，Δe 与 e 反号才保留，同号即撤回。完成标准：改进台账含前后偏差值。
输出契约：红线表 + 候选池 + 分组方案 + 改进台账格式。判停：无法定义"正常带"（无基线）时先回 model-approximation-identification / baseline-variance-control。

## B（边界）
- 盲目试错在大系统不可行（1/2ⁿ 定律）：变量多时必须先分组或先加结构约束，"错了就换"本身是失效策略。
- 开关边界依赖至少一个稳定形式存在（18.1 前提）：候选池全部不可行时机制空转——候选池要经过可行性验证，不是凑数。
- 万能自适应是幻觉（18.4 折衷原则）：只为枚举出的具体风险做预案；未识别的风险走通用应急流程，不硬套开关。
- 切换有成本：频繁触线说明系统设计有问题（回 stability-health-check 查发散回路），不应把开关当常态运行模式。
- 方向性检验是必要非充分条件：偏差缩小不等于全局最优，但偏差扩大的动作一定错误。
