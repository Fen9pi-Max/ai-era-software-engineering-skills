# 最速冲刺与切换时机（bang-bang + 存在性优先 + 终点补稳 + 危险区间快穿）

## R（原文摘引）
> 当控制量受限制时，线性系统内的最速控制必定是开关式函数。布绍的方法虽然只限于二阶系统的讨论，但它的普遍意义在于这样一个事实……过早的开关动作是不利的。……过迟发生开关动作也是有害的。（第八章 8.1/8.2）
> 并不是所有的情况下，最优控制都存在。因此，在进行控制设计时，首先重要的是搞清楚最优控制是否存在。否则，寻求最优控制的努力可能是徒劳的。（第九章 9.1）
> 当最优控制找到以后，在某些闭环系统中，设计控制装置时还要考虑到控制系统在终点状态是否稳定。（第九章 9.1）
> 如果尽可能迅速地通过"危险区域"，就可以使不利的效果减少到最低的程度。（第一章 1.2）

## I（解释）
1. **存在性第一问**：寻求"最优方案"前先问这个问题有没有最优解——只有"满足标准 + 可终止"的解？目标如"零缺陷且零延期"可能属于"多解但无极小"（可无限逼近不可达），此时改设满足性标准 + 停止规则，避免团队在不可收敛的优化上空转。
2. **受限资源下最快 = 开关式**：资源上限明确且目标是尽快达标时，最优策略是"全力冲刺或全力收缩"，不在中间档位匀速磨蹭。半力投入拉长暴露时间，总代价更高。
3. **切换时机是设计对象**：从冲刺切回稳态的时点过早（未达标就松劲）或过迟（过冲后才发现）都加总时间；且切换次数有界（n 段定理精神：频繁反复横跳必非最优）——先定切换判据再冲刺。
4. **终点补稳**：最优冲刺方案设计完必须单独回答"到达里程碑后如何站稳"——恢复正常节奏、偿还冲刺债（测试债、疲劳、文档缺失）的保持机制。最优过渡 + 不稳定终点 = 不可实现的方案。
5. **危险区间快穿**：高风险窗口（重构、迁移、交接、发版）应集中资源缩短暴露时间，而非在危险区间里慢慢试探；同时压低进入窗口前的存量问题（初始扰动）。

## A1（原书案例 + 合成演练）
- 原书：控制量受幅值限制时最速控制必为开关式（8.2，n 段定理：变号次数 ≤ n−1）；"推物体到位且耗能最小"问题最优解不存在（9.1）；最优过渡过程设计完还要补终点稳定装置（9.1）；变系数系统快速通过不稳定区间可把偏差峰值压到最低（1.2）。
- 合成演练（原书未提供项目案例）：距硬性发布窗 4 周、缺口 2 周工作量、可借调上限 5 人 → 存在性检查：达标可行（非无解）→ 开关式：前 2 周全员冲刺（借满 5 人），切换判据 = 集成完成 + 回归通过率 ≥95% → 到点切换：借调人员归还、冻结特性、进入 1 周稳定窗口（只修缺陷不加功能）+ 冲刺债清单（2 项测试债、1 项文档债）排入下迭代。若误判切早（集成未完就撤人）→ 二次冲刺，总时间反增。

## A2（情境应用）
场景：赶工决策（加多少人、加多久）时；决定何时停止冲刺转入稳定时；设定"够好就停"的标准时；高风险迁移/重构窗口规划时。
语言信号：「赶得上吗」「要不要全力冲一把」「什么时候收手」「差不多了吧能不能停」「crunch mode / all-in / 冲刺 / 止损 / 停止标准」。
区分：stability-health-check 判健康状态；本卡是资源受限下的时间最优策略；multi-objective-tradeoff 处理"不是只求快"的场景（若速度非主要矛盾，匀速可能更优）。

## E（执行步骤）
输入契约：目标与硬时限 + 当前缺口 + 资源上限（可调动人力/预算的真实边界）+ 风险窗口清单。
1. 存在性检查：目标在时限与上限约束下可达吗（不是"几乎可达"）？不可达 → 重谈目标或转 multi-objective-tradeoff 取舍；可达但"最优"不可定义（如"零风险上线"）→ 改设满足性标准 + 停止规则。完成标准：三选一判定 + 依据。
2. 开关式方案：冲刺期 = 资源用到上限；同时写下切换判据（可观测、可判定，如"回归通过率 ≥ X% 且 Y 项闭环"），预估切换次数 ≤ 方案维度数，超过即视为方案反复。完成标准：冲刺方案 + 切换判据 + 反复预警线。
3. 终点补稳方案：到达后如何站稳——稳定窗口长度、冻结规则、冲刺债清单（测试/文档/疲劳）及其偿还排期。完成标准：无此项的冲刺方案不得放行。
4. 危险区间处理：识别方案中的危险区间（一次性迁移、不可逆操作），为其设计"集中资源快穿"（加大通过速度）+ 降低进入前存量（先清障再入窗）。
输出契约：存在性判定 + 开关式冲刺方案 + 切换判据 + 补稳方案 + 危险区间快穿安排。判停：资源上限未确认前不出方案（无界资源下"最快"无意义——8.2 明言）。

## B（边界）
- 前提是资源确实受限且时间是主要矛盾；资源宽松或质量为主要矛盾时，开关式只会制造过载（对照 multi-objective-tradeoff）。
- 开关式策略在目标附近会引起抖振并放大噪声（8.8 警告）：切换判据必须带缓冲带（如通过率阈值留 3% 余量），且阈值大于日常波动（noise-filtering-estimation）。
- 全力冲刺的隐含代价（疲劳、质量债、离职风险）必须在补稳方案中显式偿还，否则是透支不是最优。
- 存在性判断"往往只能从技术问题的物理概念中寻求解答"（9.1）——判断依据要写实（历史数据、产能测算），不许"我觉得行"。
