# 决策规则速查 — 工程控制论（上、下册）

| 能力 | 一句话规则 |
|---|---|
| 项目稳定性体检（稳定性优先+裕度度量） | 先判关键回路是否发散（一票否决），再量各参数距失控边界的裕度，薄裕度项优先防护 |
| 多目标指标体系与权衡（六项清单+主要矛盾+向量指标） | 指标按对象定制后逐维独立评价，抓当前主要矛盾显式取舍；拒绝加权总分，保帕累托集 |
| 反馈回路与节拍设计（采样周期+双阈值告警+有限收敛） | 闭环=测量-比较-纠偏缺一不可；节拍快过漂移慢过噪声，连续 N 次确认才升级、M 次正常才解除 |
| 建模与估算（工程近似边界+控制量受限+辨识三法） | 简化是带边界声明的决策；计划显式列资源硬上限；实测与历史数据优先于结构分解推算 |
| 噪声过滤与状态估计（通频带权衡+原理性下限） | 平滑窗口取信号失真与噪声漏过的折衷；与噪声叠接的频段原理上不可分辨，出路是改测量 |
| 基线与偏差管理（摄动制导范式） | 离线建可信基线，执行期只测偏差判传播；偏差超线性域就重定基线，不在旧基线上硬追 |
| 自寻最优点的试探迭代（连续测量+步长律+0.618 优选） | 用控制中连续测量代替预先了解；步长随反馈幅度调节；单峰参数用 0.618 法最少试验逼近最优 |
| 时滞补偿（历史区间思维+最坏情况设计） | 当前状态由一个延迟窗口内的历史决定；盘点在途动作防重复用药；按最坏延迟设计仍收敛的纠偏 |
| 多团队解耦与协调（互不影响设计+协调三原则） | 先分清要解耦还是协调；有害耦合切断有益耦合保留；解耦设计只落在管理者可变的接口层 |
| 最速冲刺与切换时机（bang-bang+存在性优先+终点补稳） | 资源受限下最快=全力冲刺或全力收缩+准时切换；先问最优是否存在；冲刺方案必须配终点站稳机制 |
| 冗余与容错设计（自检+热备/冷备/k-N 表决+可靠性口径） | 串联链路成功率=各环节乘积先找瓶颈；冗余按失效代价选热备/冷备/表决；同源副本不算冗余 |
| 自适应与自镇定（开关边界+复杂度定律+分组隔离+方向性检验） | 预设红线边界触线即切换候选方案；大系统盲试不可行（1/2ⁿ）先分组；改进动作必须使偏差缩小 |
| 大系统分解-协调（多级递阶+切断重连+全局协调必要） | 分层是信息结构必然（集中不可能）；切断独立设计再分析耦合；局部最优必须配显式全局协调 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
