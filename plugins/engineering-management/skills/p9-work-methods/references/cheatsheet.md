# 决策规则速查 — P9 工作法：夯实技术硬实力、架构力和领导力

| 能力 | 一句话规则 |
|---|---|
| 好代码构造与安全重构 | 以"一眼看到底"为唯一标准构造代码；重构用 ROI 三问决策、先补用例再动手、以逻辑等价收尾。 |
| 系统分析文档标准范式 | 系分不是文档任务而是把逻辑推导书面化以达成共识——按"上承需求、下启代码、守住底线、精益求精"四维度成文，用评审五环节收口。 |
| 接口契约设计与落地 | 跨团队复杂协作必用接口契约：存量只还原事实、新增按三要点立规则（字段无二义+S/F/U 结果结构+报文样例）、契约测试建质量栅栏、统一管理对抗破窗。 |
| 领域建模四招与边界 | 有状态、有不变量要守护的业务域才建模；建模走四招，实体过六要素坏味道检查，编排与查询类不建模。 |
| 自测用例设计与灰犀牛治理 | 自测先穷举用户场景、闭环链路与可感知异常，再为关键设计写断言用例；用例是熵增资产，不治理就从资产变灰犀牛。 |
| 幂等性与错误码排障 | 重复处理查幂等三维（字段唯一稳定守契约、存储单点加全局检查、逻辑一锁二判三更新）；状态错标按错误码三态——非明确成功失败一律置未知，推拉补偿到终态，超窗置失败。 |
| 分布式事务与缓存风险治理 | 跨系统一致性先按"一致性要求×团队条件"选事务方案（2PC 或事务消息+幂等），缓存引入先过三不适用否决，再按四源加固可用性、按五场景定一致性策略。 |
| 异步化与高可用盲区治理 | 异步化=用时间换容量，任务先定 deadline 并防三源时效失效与回查错判；高可用先把状态剥离到数据层，再按流水/状态两型选 FailOver，用发现/应急/善后机制弥补不完美方案。 |
| 日常软技能操作法 | 软技能当硬流程执行：要事用两问识别并纳入协作流程拒绝，沟通先找共同利益再选最近媒介，表达按受众-结构-重点三步，会议先算成本再按五要点经营，协作先方案后分工、补位前先归位。 |
| 应急处置与风险暴露 | 故障时先问"业务恢复了吗"再谈找原因（预案>回滚>查因修复），风险则分级定时限、拿数据带解法、向有决策权的人说——大风险的暴露时机只有"即将发生时"和"现在"。 |
| 架构师三心魔自检 | 动架构之前先过三道心魔自检——完美主义用确定性三件事（可感知指标/决策树SLA/紧贴当下的承诺）解，风险主义用概率观加恒等式与等份划分解，单一主义用"三类答不了的问题"与选择权三角解。 |
| 架构建模三式（繁简/虚实/无有） | 应用类架构难题先归类再选式——繁（逻辑混乱）用"定义物理元素实体→一横多纵→最复杂场景验证→批量释放红利"，虚（解法不明）用"回到根本→理论公式→能力树→性能参数"，无（问题不清）用七见定位加五步生长。 |
| 高可用·资损防控·兜底设计 | 不追求消灭风险，先用 E(X)=(ΣP)×R×F×T 与 L/S/D×T 量化影响，再用四大高可用设计+资防四式+事前事中事后三段兜底逐因子压缩它 |
| 架构演进的经营方法 | 以经营者姿态推进演进：从信息结构混乱觉察启动，用物理删除代码的极致目标（三个100%）+里程碑跟踪+大盘图论证+七字段决策文档+三个场子传承滚动前行 |
| 架构师系统思维与角色定位 | 先定生态位（业产技三角+军师/法官/巡警三权责），再按问题形态从思考六式选式执行，四特征筛关键点亲自审查、三层深入看本质、四面镜子自省 |
| 团队目标与绩效管理 | 凡涉及给团队或成员定目标、追过程、打绩效、谈绩效面谈，走 ISMART→三追→赏罚分明→三段对话的闭环，不走拍脑袋与横向比较。 |
| 技术规划的目标拆解与咬合 | 凡产出或评审年度技术规划，走 WHY 追问求高度→WHAT-HOW 探底求深度→奥卡姆剃刀求锐度→目标三咬合→拆解（事+人）→里程碑进度条，底盘投入单列三年工程。 |
| 团队成长与主管自我修炼 | 凡团队要上台阶（专业性暗线、负反馈问题清单、新人融入）或主管要修炼自身（本职四抓、精力 4:3:3、影响力、成长双引擎），用本能力，不用绩效周期工具。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
