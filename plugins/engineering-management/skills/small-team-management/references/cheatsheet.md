# 决策规则速查 — 如何管理10人以下小团队：谷歌核心团队实现10倍速成长的高绩效秘诀

| 能力 | 一句话规则 |
|---|---|
| 抱怨→期望转换（接发球对话） | 听完不打断，用"你是希望……吧？"把抱怨转成期望，引出对方认领的行动，以"你提的意见很好，谢谢你"收尾。 |
| 冲突调解与两类对立 | 先分观点对立（多多益善，引向"你的诉求是什么"）还是情绪对立（需调解：换房间→各述诉求→交叉复述→自行修复）；价值观根本分歧不调解，靠任务清晰+人尽其才调岗。 |
| 员工体验与理念共创 | 把成员从录用到离职当一段旅程：逐触点设计宝贵瞬间、消除负面触点，靠小确幸日积月累而非一次性活动；照顾感受=开口前预演"对方会怎么想"；理念由全员共创并定期修订。 |
| 实验主义与创造性混乱 | 用草案换速度：完成到"能讨论"就拿出来全员挑刺、当周用最便宜的资源试探、计划不现实就果断弃；唱反调只砸常识和流程，绝不砸人。 |
| 反馈与前馈循环 | 事前问准备、补风险（前馈），当天给具体亮点+一处改进（反馈），且每条反馈必须落进下一次前馈，否则不给；讨论必须带能推进下一步的预案。 |
| 高效团队5要素诊断 | 用亚里士多德计划5要素给团队体检；安全感缺失时其余4项一律判"无法评估"，改进永远先补安全感。 |
| 整合型管理者与做减法 | 管理者不做本团队日常、把成员当资源而非助理：工作分四桶（成员能学的委派/可机制化的自动化/可外包的外包/必须做的保留），以"管理者不在场团队照常运转"为验收；业绩口径=成员的成果。 |
| 卓越管理者8项特质自检 | 用氧气计划8项特质对照行为证据自检管理者自身；教练项不合格一票否决，第一优先级永远是补教练。 |
| 管理者姿态：袒露弱点、谦逊与性善论 | 管理者坦率认错、四段式（背景/承认困难/具体请求/补偿）交办求助；严厉只用于高层次职业技能要求且以平时亲切为前提；底层是谦逊、性善论与无条件积极关注。 |
| 管理者职责与经营者视角 | 成员表现不佳先查管理者四问（目标/过程/反馈/1on1），未经1on1不得断定"不得力"；一切业绩以高层经营者的评价为最终口径。 |
| 团队机制设计库 | 机制先从自己的商业模式倒推再选型（照搬＝铃木效仿保时捷）：定位瓶颈→对照机制库选型（简报/同事奖金/二人组/过度沟通/巧遇/自动化/尽早失败）→一个月试用→迭代或替换，目的是管理者不在场团队照常运转。 |
| OKR 制定规则 | OKR 是员工对"公司要什么、我能贡献什么"的自主回答：从公司利润倒推、SMART 校验、野心校准到完成度约 70%、公开可查、每周检视、无意义即弃；绝不把流程维护或考核得分当 OKR。 |
| 一对一面谈与教练提问体系 | 每周每人1小时、时间属于成员：用GROW与7问等价值观提问做教练，进度核查不进1on1，职业规划三次间隔不突击。 |
| 三次反思与反学习节奏 | 会前预会想清要什么结果、会中关注成员状态、会后复盘写入下一次；月度反思日检视工作还重要吗，落伍思维果断反学习。 |
| 因人而异沟通与情境领导 | 表达方式因人而异、权利层一视同仁；按能力×意愿四象限选授权/鼓励/指导/指令，用和善-严厉-魅力三原则托底每次沟通。 |
| 减法评价与双轨反馈 | 评价=业绩轨（对照OKR）+行为轨（从100%减法、扣分须有具体事由），总评必须附恢复路径，面谈四段话术引导行为改变而非通报。 |
| 团队构成：迪士尼策略、跨度与文化扩展性 | 用"思维方式多样性"而非人员构成选人：迪士尼三角色（梦想家/实干家/批评家）查均衡、用 1on1 时间账核算管理跨度≤7、用流动机制与文化扩展性（culture add）防团队固化。 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
