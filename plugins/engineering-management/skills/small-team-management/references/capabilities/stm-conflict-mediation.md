# 冲突调解与两类对立

## R（原文摘引）

> "每次遇到这种情况，我都会把争执的双方带到另一个房间，听取他们的说法。"（第2章 ◆如何调解成员之间的纠纷）

> "首先请他们充分说明自己的意见，确认A希望B做什么，B希望A做什么。在此基础上，先请A复述B的需求：“你知道B希望你做的是什么吗？”然后再同样请B复述A的需求：“请你说说A希望你做的是什么。”"（第2章 ◆如何调解成员之间的纠纷）

> "只要两个人互相认识到对方对自己的诉求，情绪化冲突就会立刻缓和下来。之后，双方便可以通过建设性沟通主动修复彼此的关系。……管理者需要做的调解不是单方面提出解决方案，而是不动声色地让当事人说出自己的意见。"（第2章 ◆如何调解成员之间的纠纷）

> "虽然都是对立，观点上的对立越多，情绪化的对立就越容易自动消解。为此，管理者需要提升团队安全感，让成员知无不言，言无不尽，说到底这也是一项重要职责。"（第3章 ◆"多多益善的对立"与"尽量避免的对立"）

> "“哦，你是希望B做×××吧？”……“那么你跟B说过你希望他这么做吗？”……“那下次团队会议上，你可以这样建议B试试。”……只要用“要求”代替抱怨，让对方意识到自己的诉求，把对话引导到建设性的方向就可以了。"（第2章 ◆用要求代替抱怨）

> "只有确保任务清晰明确，才能从一开始就避免这种价值观层面上的分歧。……对无法认同这一点的成员，管理者应该通过反复的建设性沟通，从“人尽其才”的立场出发，考虑包括岗位调动等相应措施。"（第3章 ◆最具建设性且最高效的关系）

## I（解释）

这套方法先做一个分流判断：对立分两种。观点对立（对方案、对事）是安全感和多样性的体现，多多益善，管理者不仅不扑火，还可以主动升温（"真的就只有这一个办法吗？"）；情绪对立（对人、翻旧账）要尽量避免，一旦出现就得调停。观点对立越多，情绪对立越容易自动消解——所以日常要做的是让观点充分交锋，而不是维持一团和气。

调解的程序核心是"管理者不裁决"：不提解决方案、不判断对错，而是设计一个让当事人自己说出意见的流程。三步：把双方带到另一个房间（隔离现场降温）→ 各自充分说明，确认"A希望B做什么、B希望A做什么"→ 交叉复述——请A复述B的需求，再请B复述A的需求。当两个人互相认识到对方对自己的诉求，情绪会立刻缓和，后续关系修复由双方通过建设性沟通自己完成。

单方入口是轻量变体：A跑来抱怨B时，用"要求"代替抱怨——期望句确认诉求（"你是希望B做×××吧？"）、确认是否直接沟通过（"跟B说过吗？"）、引导当面表达（"下次团队会议上建议B试试"）。

机理上，最激烈的冲突发生在自己一直遵循的信念或价值观遭到否定时，命令（"照我说的做"）无法避免情绪化冲突；有效路径是温和追问挖掘本质欲望（"你为什么想……？除了……还有什么别的也……吗？"）再提供替代选项。而价值观层面的根本分歧（如自上而下 vs 自下而上）不可调和：预防靠团队任务清晰，对无法认同者从"人尽其才"出发考虑调岗——那是组织问题，不是调解问题。

## A1（原书案例 / 合成演练）

**案例一：三外企的情绪化冲突调解（firsthand，第2章 ◆如何调解成员之间的纠纷）**。输入：作者先后在贝立兹、摩根士丹利、谷歌工作，"无论由多么优秀的人才组成的团队，都发生过大大小小的争执"，谷歌个性员工尤多情绪化冲突。执行：每次都把双方带到另一个房间，按"各自说明→确认相互诉求→A复述B需求→B复述A需求"调解。输出：作者断言"只要两个人互相认识到对方对自己的诉求，情绪化冲突就会立刻缓和下来"，之后双方通过建设性沟通主动修复关系（具体单案细节与结果未说明）。

**案例二：A抱怨"B是不是太过分了！"（worked_example，第2章 ◆用要求代替抱怨）**。输入：成员A跑来向管理者抱怨成员B。执行：三步话术——"哦，你是希望B做×××吧？"（A："嗯，是的。"）→"那么你跟B说过你希望他这么做吗？"（A："没有。"）→"那下次团队会议上，你可以这样建议B试试。"输出：A意识到自己的诉求，获得直接沟通的行动路径（结果未说明）。管理者也借此了解团队内部的情绪化冲突。

**案例三：孩子看电视（worked_example 家庭场景迁移，第2章 ◆"照我说的做"解决不了问题）**。输入：孩子想一直看电视，母亲命令"你不许老看电视！"引发闹情绪反抗；"照我说的做"说多少遍都没用。执行：温和追问链——"你为什么想看电视？""因为好玩。""那为什么想做好玩的事呢？""因为开心啊。""除了看电视，还有什么别的事情也是开心的吗？""和爸爸妈妈一起出去玩也很开心。""好，那咱们就一起出去玩吧。"输出：对抗转为共同选项；作者指出对团队成员同样使用——引导当事人认识问题本质，提供更多建设性选项（作为方法示范，无后续结果交代）。

**案例四：培训团队的路线之争（worked_example，第3章 ◆最具建设性且最高效的关系）**。输入：培训团队策划活动，成员A倾向"自上而下"，成员B喜欢"自下而上"。执行：识别为价值观层面根本分歧——一次摩擦可忍耐，长此以往关系恶化、效率下降；处理是把团队任务定清晰（如"自下而上进行培训"），对无法认同的成员通过反复建设性沟通，从"人尽其才"立场考虑岗位调动。输出：分歧从"人际摩擦"转为"任务与配置问题"（结果未说明）。

**案例五：接纳训练（firsthand 培训实践，第2章 ◆如何调解成员之间的纠纷）**。输入：作者在培训活动中长期进行的"接纳训练"。执行：参与者说出希望/不希望别人关注自己的部分（"我希望你关注我智慧的一面，不希望你看到我随性的一面"），对方不仅接纳还发现更多闪光点（"我还看到了你宽宏大度的一面"）。输出："每次进行这项训练时，会场的气氛都会非常愉快"——复述调解法即其变化形式。

## A2（情境应用）

**触发场景**：
- 两名成员争吵、互相指责、邮件抄送互撕，或陷入冷战影响协作；
- 一方（A）跑来向你抱怨另一方（B），你判断两人之间已有对立；
- 会议讨论升温，你不确定该鼓励争下去还是踩刹车；
- 同一矛盾以不同面目反复出现，双方各自"忍着"、私下积累怨气。

**语言信号**：
- 中文：冲突、吵架、闹翻了、撕破脸、调停、调解、争执、对立、互相甩锅、价值观不合、两个人打起来了怎么劝
- 英文：team conflict, mediation, facilitate a dispute, feuding coworkers, two team members fighting, emotional conflict, opinion vs emotional disagreement, resolve conflict between peers

**与相邻能力的区分**（初稿）：
- 与 stm-complaint-conversion：那是"一个人向你抱怨事物/工作"的单方接话；本能力是成员之间的双方冲突，管理者作为第三方介入。A抱怨B属跨界场景：先用本能力的"用要求代替抱怨"三步（冲突未升级），升级为正面冲突才进调解程序。
- 与 stm-one-on-one-coaching：那是定期面谈的结构与提问；本能力是事件触发的调停程序（其中"分别听取"可借用 1on1 形式）。
- 与 stm-manager-posture：那是管理者自身的姿态（认错/求助/严厉）；本能力中管理者是中立调停者，不是当事人。
- 与 stm-situational-communication：那是按成员特点选沟通模式；本能力按对立类型选处理程序。

## E（可执行步骤）

1. **分类：判断对立类型**。检查两点——焦点（针对方案/观点，还是针对人？）与情绪（内容逻辑还在，还是音量、翻旧账、动机归因已压过内容？）。观点对立 → 走第 2 步引导，不调停；情绪对立 → 走第 3 步调解；反复爆发且围绕方向性分歧 → 直接跳第 5 步判定价值观分歧。完成标准：写出"焦点=方案X/人Y；情绪=高/低"的判断依据一句话。

2. **观点对立引导法**（判停点：引导中出现人身攻击或动机归因"你就是想……" → 立即转第 3 步）。把讨论引向诉求表达："你的诉求是什么？""我希望实现××"；要求反对针对创意本身并保持建设性（"我觉得这个地方可以这样改""这方面没有数据支撑，不太有说服力"）；必要时主动提升紧迫感激发创意："你们讨论了这么久，真的就只有这一个办法吗？应该还有其他更好的主意吧？"完成标准：双方在用"我希望……"句式交流，且无人身评价。

3. **情绪冲突调解流程**：
   - 3.1 带到另一个房间（隔离现场、降温；远程团队替换为分别单独听取——外推约定）；
   - 3.2 各自充分说明自己的意见，管理者确认并记下"A希望B做什么""B希望A做什么"；
   - 3.3 请A复述B的需求："你知道B希望你做的是什么吗？"
   - 3.4 请B复述A的需求："请你说说A希望你做的是什么。"
   - **判停点：复述后仍未缓和**（复述走样、继续指责对方）→ 回到 3.2 分别再听取，重新确认双方诉求后再试一轮；仍无效则按第 5 步检查是否价值观分歧。不强行撮合，绝不单方面抛解决方案或裁决对错（编者按原书逻辑补全的失败分支，原书未明说）。
   - 3.5 缓和后管理者退后，让双方通过建设性沟通自行修复关系。
   完成标准：双方各自复述对方的诉求且被对方认可"是这么回事"；结束时存在双方都认同的下一步（哪怕是"下周再谈"）。

4. **单方抱怨入口（用要求代替抱怨）**：A向你抱怨B时依次问——①"你是希望B做×××吧？"②"那么你跟B说过你希望他这么做吗？"③"那下次团队会议上，你可以这样建议B试试。"完成标准：A带着一句可以直接对B说的"要求"离开，而不是带着对你的共鸣离开。

5. **价值观根本分歧判定与处理**：调解/引导多轮后冲突仍围绕方向性分歧（如自上而下 vs 自下而上、路线之争）反复爆发 → 判定为价值观层分歧，停止就事论事调解：①检查团队任务（愿景/战略）是否清晰明确——任务清晰能从源头避免这类分歧；②对无法认同任务方向的成员，通过反复的建设性沟通，从"人尽其才"的立场出发考虑岗位调动等相应措施。完成标准：书面结论——该冲突属"可转化对立"或"价值观分歧"二选一，及对应路径（继续第 2/3 步 / 任务澄清+调岗沟通）。

**温和提问挖掘本质**（第 2、3 步内可随时使用）："你为什么想……？""那为什么想做……？""除了……还有什么别的事情也……吗？"逐层挖到积极意愿层，再提供替代选项。

**输入契约**：必需 = 冲突双方及事件描述（谁对谁做了什么）、当前状态（观点交锋/情绪爆发/冷战）、是否已有单方向管理者的抱怨。缺失时先分别听取补全，绝不凭一面之词启动调解或下结论。

**输出契约**：对立类型判定（观点对立/情绪对立/价值观分歧）+ 对应处理脚本（引导话术 / 六步调解程序含判停 / 任务澄清+调岗路径）+ 后续跟进事项清单（如"下次团队会议上 A 当面建议 B"）。

## B（边界）

**反场景（何时不用；标 ※ 者为合理外推，原书未涉及）**：
- ※ 法定纠纷、HR 正式投诉、骚扰/暴力事件——调解话术（尤其"双方对质互复述"）可能对当事一方造成二次伤害，必须走正式流程；
- ※ 严重权力不对等的冲突（如上级对下级的职权压制）——复述程序默认双方地位对等，权力悬殊时先单独评估，不直接安排对质；
- 把观点对立误判为情绪对立去"调解"——会扼杀多多益善的争鸣（书中立场：观点对立越多越好，是效率的契机）；
- 单纯的意见征询、方案评审（无对立）——直接用建设性反馈规则，不需要本能力程序。

**书中警告的失败模式（候选反例 id）**：
- ce-14 "照我说的做"式单方面裁决/直接下令——冲突表面平息实则反复，当事人信念未被触达；
- ce-28 团队任务不清导致价值观摩擦长期化——靠忍耐拖延，关系不断恶化、效率越来越低；
- ce-33（第4章同族）谴责提案人而非创意本身——争论无建设性结果，成员学会"多提多错"。

**作者盲点/时代局限（阶段 0 批判）**：
- "互相复述后情绪立刻缓和"是作者的经验断言，全书未给出转化失败时的处理细则（本卡 3.4 判停为按原书逻辑补全的合理外推，已标注）；
- "调岗"出口假设组织允许人员流动，强科层、编制紧张的组织难以落地；
- 案例集中于外企（贝立兹/摩根士丹利/谷歌）语境；"带到另一个房间"的物理隔离在远程团队需替换为分渠道分别听取（外推），书中未讨论远程冲突。
