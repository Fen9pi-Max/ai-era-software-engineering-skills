# 决策规则速查 — 测试之美（Beautiful Testing）

| 能力 | 一句话规则 |
|---|---|
| 测试干系人满意与度量体系 | 干系人识别+三维评价+DDP/ROI/RTA/RRC/ART 度量公式（GQM 构建） |
| 模糊测试三级策略 | 常规→自定义→随机三级模糊，缺陷库种子+问题文件回归库 |
| 测试用例有效性（TCE）与缺陷管理 | TCE=(Nt/Ntot)×100% 加权计算+逃逸六类归因+缺陷报告 5W 规范 |
| 性能测试协作方法 | 阈值式需求改写+性能检查点+白板使用模型+异常排查协作规则 |
| SLIME 高效测试顺序与实用脚本 | 安全→语言→新增→度量→已存在的测试排序+图案化文字+oracle 脚本 |
| 变异测试：评估测试集质量 | 植入变异评估测试集：核心算子+三优化+影响排序过滤等价变异 |
| 大规模测试自动化运营 | 唯一ID+集中构建+实验室分配+自动失败分析+100%失败调研的运营体系 |
| 协议测试四层抽象与场景测试 | 逻辑与表示分离的四层断言+响应表自动应答+场景帮助方法 |
| 以变化为中心的测试 | 调用图+测试映射+三度分离规则生成动态回归清单 |
| 测试之美核心原则 | 顾问非把关人、检验≠调查、均衡组合、黑天鹅回归取舍等原则集 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
