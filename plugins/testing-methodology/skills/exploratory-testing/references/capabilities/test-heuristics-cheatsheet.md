# 变量识别与测试启发法速查

## R（原文摘引）
> 在测试的世界里，变量就是你在操作软件时可以改变的或间接地引发改变的任何东西。（第4章4.1）

> 穷举测试就是测试员已经累到吐血无力继续测试。（第4章开篇）

## I（解释）
变量三分类：**明显**（表单字段、API 参数——常被充分测过，但值的特征可选得有趣：对称输入"101"掩盖位序错误，"011"不会）、**微妙**（URL 参数、隐藏配置、cookies、输入速度——Therac-25 的 8 秒、第 256 次运行）、**可间接访问**（已登录用户数、搜索结果数、某条件出现与否——最有趣）。
变量种类→启发法映射：
- 可计数之物 → **零、单、多**；**过多**；**过少**；**零**（空集合/0 个朋友即崩溃）
- 相对位置 → **开始、中间、结束**（删最后一条、粘贴到行尾）
- 成组条目（权限/复选框）→ **部分、全无、全部**
- 大小/范围 → **金发女孩**（太大/太小/刚刚好），2 的幂边界（256 字符）
- 格式 → **违反数据格式规则**（负数年龄、2月31日、非法 XML、垃圾文件）
- 层级 → 深度（嵌套 4 级表格指数变慢）
- 文件/存储/位置 → 移动、自定义路径、异地、随机地理位置
- 时间点/频率/持续时间 → 提速、重复、闲置超时、开一整夜
- 输入和导航 → 键入 vs 粘贴 vs 拖放
补充启发法：**集中一切/分散一切**、**逆向**（撤销一切/跳到结尾反向走）、**干扰**、**挨饿**（扣 CPU/内存/带宽/磁盘）、**CRUD**、**跟随数据**、**抽象/变焦**、Web 专属（**后退/前进/历史**、**存为书签**——流程中间页）。书中明确：这些适用于任何接口（API/批处理/语言/Web 服务）。

## A1（原书案例）
- Therac-25：操作员 <8 秒内输入并更正治疗数据撞上磁力锁窗口；设置例程每第 256 次跳过安全检查——计数与速度两个微妙变量致人死亡。
- 阿丽亚娜 5：64 位浮点转 16 位整数溢出——平台变化使"速率"变量超限。
- 勇气号：文件**数量**（非磁盘空间）撑垮 RAM——同是磁盘变量，细节不同行为不同。
- Colin 的 API：calculateSimilarity(null,null) 抛异常；整章《汤姆·索亚》自比较 CPU 100%——0/1/多与大小启发法用于无 GUI 函数。
- JavaScript [7,3,11].sort() 得 "11,3,7"——类型变量坑。

## A2（情境应用）
面对任一接口（表单/REST API/批处理文件）：
1. 先列变量清单：按上面 9 个种类逐类扫描，明显/微妙/间接三档标注。
2. 给每个变量配启发法：计数类→0/1/多+过多过少；集合类→部分/全无/全部；数值范围→金发女孩+2 的幂；结构→深度。
3. 挑"有趣"的值：能区分实现差异的值（不对称、越界、极端格式）。
4. 无 GUI 时同样适用：批处理试 0 条/1 条/多条记录文件、空字段、非法字段。

## E（评测）
- 输入：任一系统/接口描述（如"导入 CSV 的批处理"或"用户资料编辑页"）。
- 输出：变量清单（≥10 个，含 ≥3 个微妙/间接变量）× 每变量至少 2 条启发法变化，合计 ≥20 条试验。
- 通过标准：覆盖 ≥6 个变量种类；包含至少一个 0 值情形和一个 2 的幂边界；明显 GUI 之外的变量（时间/环境/隐藏设置）不缺席。
