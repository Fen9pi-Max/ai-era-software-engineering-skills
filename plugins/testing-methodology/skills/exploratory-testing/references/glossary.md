# GLOSSARY — 《探索吧！深入理解探索式软件测试》共享术语词典

- **检查 (Checking)**: 用预先设计的测试验证软件吻合预期, 像"绊线网"。第1章
- **探索 (Exploration/Exploratory Testing)**: 同时设计并执行测试以学习系统, 据前一试验选择下一个。第1章
- **探测章程 (Charter)**: 探索的使命说明: 目标/资源/信息三段。第2章
- **限时探测会话 (Session / SBTM)**: 基于探测会话的测试管理, 时间盒+章程+记录+汇报。第1章
- **侦察探测会话 (Recon Session)**: 面向不熟悉系统的第一波会话, 产出生态系统草图/变量清单/章程清单。第11章
- **变量 (Variable)**: 探索时可改变或间接引发改变的任何事物; 分明显/微妙/可间接访问。第4章
- **启发法 (Heuristic)**: 有名字的测试变化生成规则, 如"零、单、多"。全书/附录2
- **绝不和始终 (Never and Always)**: 系统不可侵犯规则, 违背即重大问题。第5章
- **神谕 (Oracle) / 神谕之难**: 判断观察行为正确与否的真理之源。第5章
- **有效近似值**: 范围/特征/反转/环境等近似判断手段。第5章
- **实体 (Entity) / 属性 / ERD**: 系统管理的事物及其关系图。第7章
- **CRUD**: 创建/读取/更新/删除。第7章
- **状态 (State) / 事件 / 转换**: 行为模式+触发物; 状态图与状态表格。第8章
- **生态系统图 (Ecosystem/Context Map)**: 语境图+部署图混搭, GML 画法。第9章
- **信任边界 (Trust Boundary)**: 系统无法确定对端按规矩办事的地方。第9章
- **如果的话 (What If)**: 对生态系统图逐连接提问故障场景。第9/12章
- **跟随数据 (Follow the Data)**: 数据进出的每个地方检查完整性与副作用。第7/9章
- **角色人物 (Persona)**: 带名字/年龄/性格的用户原型, 扮演其交互方式。第6章
- **名词和动词 (Nouns & Verbs)**: 随机组合生成场景的技术。第6章
- **噩梦头条 (Nightmare Headlines)**: 想象灾难头条反推风险的群体游戏。第2章
- **积极阅读 (Active Reading)**: 边读边质问, 输入/处理/输出/问题四区笔记。第12章
- **可测试性 (Testability)**: 可视性+控制。第3章
- **SBTM**: Session-Based Test Management, Jon/James Bach 提出。第1章
