# 决策规则速查 — 探索吧！深入理解探索式软件测试（Explore It!）

| 能力 | 一句话规则 |
|---|---|
| 探测章程设计与限时探测会话 | 用目标/资源/信息三段章程框定探索，以时间盒会话执行、记录并汇报 |
| 变量识别与测试启发法速查 | 识别明显/微妙/间接变量，按变量种类套用启发法生成有意义的变化 |
| 观察细节与可测试性 | 克服无意视盲、深挖问题、布置日志/监控让不可见变可见 |
| 评估结果：绝不和始终、替代资源与近似神谕 | 用不可侵犯规则+替代资源+近似手段在无需求时判定行为对错 |
| 状态建模与转换探索 | 画出状态与事件，用状态表格找未探索转换，用干扰与所有途径招惹系统 |
| 实体关系与 CRUD 探索 | 识别实体属性与依赖，用 CRUD 变化与跟随数据挖掘数据类缺陷 |
| 不可重现缺陷调查 | 收集证据→列嫌疑变量→状态模型理解时机→协作，找到并控制所有变量 |
| 生态系统图与信任边界探索 | 画生态系统图（接口/外部依赖/内部组件），在信任边界上做故障注入 |
| 改变顺序和交互 | 用名词+动词随机组合、多机制导航清单、角色人物扮演改变交互方式 |
| 探索需求：如果的话与积极阅读 | 在需求会议问"如果的话"、当场起草章程；对文档做输入/处理/输出积极阅读 |
| 噩梦头条工作坊 | 想象灾难头条→选最大风险→头脑风暴原因→提炼成探测章程 |
| 遗留系统侦察与干系人采访 | 用侦察探测会话画系统地图，用三要素问题采访干系人，轻量记录调查结果 |
| 向干系人汇报与探索停止标准 | 用三问模板汇报能力/发现/未知，用四标准判断何时停止探索 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
