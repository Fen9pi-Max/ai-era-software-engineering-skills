# 决策规则速查 — 海盗派测试分析MFQ&PPDCS

| 能力 | 一句话规则 |
|---|---|
| KYM：了解测试任务（CIDTESTD 引导词法） | 用 CIDTESTD 八引导词调研测试任务：用户/项目/任务三方面信息+风险+问题清单 |
| TCO：测试覆盖大纲 | 过滤与剔除启发式重组需求信息，产出 M/F/Q+Risks+Questions 分支的覆盖大纲 |
| MFQ 三维视角：M/F/Q 拆分与分类规则 | 把被测系统拆为单功能 M/功能交互 F/质量属性 Q 三个维度并配不同测试手段 |
| PPDCS：建模特征选择（Triggers + TEST Heuristics） | 按流程/参数/数据/组合/状态五种特征与触发词，为单功能选对建模技术 |
| 建模工作流：从单功能到测试条件（TCon） | 定边界→拆分→建模→查完整性→产出 TCon+GWT+疑问清单的完整工作流 |
| 测试设计四步法：从 TCon 到测试实例（Te） | 识别变量→变化数据→多样化选取→组合出取值具体的测试实例 |
| 测试执行：反馈环、广度深度与 Fast TAD | TS-TA-TE 反馈环+更早更快更频繁+广度深度取舍+深化五手段 |
| 海盗派测试原则与观念（Tests ≠ Testing） | Tests≠Testing、启发式应用而非盲从、基于上下文等 16 条海盗派核心原则 |

> 速查只给结论；需要原文依据、案例或反例时读对应能力卡。
