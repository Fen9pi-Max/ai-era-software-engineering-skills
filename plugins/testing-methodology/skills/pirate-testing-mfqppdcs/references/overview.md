# 整书理解（阶段0）

《海盗派测试分析MFQ&PPDCS》（邰晓梅）：Context-Driven 学派（海盗派）的测试分析与测试设计方法书，以"测试=对被测系统问问题、资源有限须做明智选择"为世界观。

## 骨架（五站）
1. KYM（Know Your Mission）：CIDTESTD 八引导词调研任务
2. TCO（Testing Coverage Outline）：信息提炼/内容重组/心中有数
3. Modeling：MFQ 三维拆分 → PPDCS 选特征 → 建模 → 测试条件 TCon（GWT 描述）
4. Test Design：识别变量→变化数据→选取数据→测试实例 Te
5. Test Execution：TS-TA-TE 反馈环、更早更快更频繁、广度深度、Fast TAD

## 主例
收银机打印小票（ThoughtWorks 面试题，14 步走通建模全流程，39 TCon+16 疑问点）；大富翁（练习载体）；按摩椅（状态机练习）。

## 核心任务集
调研任务→梳理覆盖→拆分维度→选建模技术→建模出条件→落成实例→执行反馈。
