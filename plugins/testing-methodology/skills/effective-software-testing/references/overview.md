# 概览

《有效软件测试——提高测试的 50 条建议》（Effective Software Testing: 50 Specific Ways to Improve Your Testing, Elfriede Dustin, Addison-Wesley 2003，中译本）。按生命周期组织 50 条最佳实践：需求阶段→测试计划→测试组→系统构架→测试设计→单元测试→自动测试工具→自动测试实践→非功能测试→测试执行管理。核心论点：缺陷预防经济学（修正代价 $1→$100+）、测试左移、自动化是微型开发生命周期、非功能需求须前置、缺陷流程与度量是管理基础。2003 年的具体工具已过时，但决策框架与流程规范仍然成立，需映射到当代 CI/CD 与测试框架生态。
