# 整书理解（阶段0）

《自动化测试最佳实践》（ Dorothy Graham & Mark Fewster 编）是 29 个真实案例研究集，覆盖敏捷、数据库、SAP、嵌入式/汽车/医疗、空管、金融交易、云端 TiP 等领域。

## 主旨
自动化成功的两大要素：**管理支持**（切实目标、足够资源、ROI 监督）与**测试件架构**（正确抽象层）。自动化测试就是软件开发。

## 骨架
- 第0章：全书教训总结（管理问题 0.1 / 技术因素 0.2）
- 第1-11章：通用历程与框架演进（敏捷、数据库、云端、政府、10年长青）
- 第12-22章：特定领域（政府、医疗、SAP、金融）与方法（可靠性、MBT、后门、可移植性）
- 第23-28章：演化、猴子测试、空管 SoS、汽车、BHAG 转型、探索性自动化

## 核心任务集
启动自动化（试点/目标/ROI）→ 选型与决策（自动化什么）→ 框架设计（抽象层）→ 运行治理（标准/验证/失败分析/生命周期）→ 特定方法（MBT/猴子/可靠性）→ 诊断失败（反模式）
